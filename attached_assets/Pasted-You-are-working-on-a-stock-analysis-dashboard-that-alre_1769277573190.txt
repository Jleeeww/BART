You are working on a stock analysis dashboard that already includes broker flow (bandarmology) data and an AI analysis pipeline.

Your task is to add a new institutional metric called “Broker Control Score” and integrate it into both backend analysis and the frontend Flow tab.

🎯 FEATURE PURPOSE

Broker Control Score measures how concentrated net accumulation is among the top brokers.

This helps detect whether price movement is:

Broadly supported (healthy trend)

Controlled by a few brokers (higher manipulation risk)

🧮 BACKEND — CALCULATION

Broker data already exists in this format:

type BrokerFlow = {
  broker: string
  buyValue: number
  sellValue: number
}


Net flow per broker:

net = buyValue - sellValue

➕ Create a new utility function

Create a new file if needed (example: lib/bandarmology.ts) and add:

export function calculateBrokerControlScore(brokers: BrokerFlow[]) {
  const positive = brokers
    .map(b => ({ ...b, net: b.buyValue - b.sellValue }))
    .filter(b => b.net > 0)

  if (positive.length === 0) {
    return {
      score: 0,
      level: "None",
      interpretation: "No broker accumulation detected."
    }
  }

  positive.sort((a, b) => b.net - a.net)

  const top3 = positive.slice(0, 3).reduce((sum, b) => sum + b.net, 0)
  const total = positive.reduce((sum, b) => sum + b.net, 0)

  const score = Math.round((top3 / total) * 100)

  let level = "Low Concentration"
  let interpretation =
    "Accumulation is distributed across many brokers, suggesting broader institutional participation and healthier trend structure."

  if (score >= 70) {
    level = "High Concentration"
    interpretation =
      "A small number of brokers control most accumulation. This increases continuation probability but raises exit volatility risk if they reverse."
  } else if (score >= 40) {
    level = "Moderate Concentration"
    interpretation =
      "Accumulation is somewhat concentrated. Price movement has institutional support but still depends on key broker behavior."
  }

  return { score, level, interpretation }
}
