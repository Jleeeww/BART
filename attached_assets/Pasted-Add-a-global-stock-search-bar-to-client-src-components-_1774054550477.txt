PART 2 — Search API endpoint

In server/routes.ts, add this endpoint:

GET /api/search?q={query}

Logic:
  - Get query param q, trim it, uppercase it
  - If q is empty or less than 1 char, return []
  - Filter stocks from existing in-memory stock data (same source as /api/stocks)
  - Match if stock.symbol.includes(q) OR stock.companyName.toLowerCase().includes(q.toLowerCase())
  - Return max 8 results
  - Each result: { symbol, companyName, price, changePercent }
  - No new DB queries needed — use whatever stock data is already loaded in memory
