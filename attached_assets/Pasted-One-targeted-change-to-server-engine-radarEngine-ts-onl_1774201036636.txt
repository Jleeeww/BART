WHAT TO CHANGE:

In the processStock() function, find where the engine input
is built. It currently calls:

  const input = buildBandarmologyInput(raw, m6History);

This reads netFlowHistory, priceHistory, and avg20dValue 
directly from the raw stock record (static DB fields).

Replace this entire block:

  const m6History = await withTimeout(
    getM6History(symbol, 5),
    2000
  ).catch(() => [] as number[]);

  const input = buildBandarmologyInput(raw, m6History);

With this:

  // Load real session history from session_history table
  // Falls back to raw record fields if history unavailable
  const { buildStockHistory } = await import('./historyBuilder');
  
  const history = await withTimeout(
    buildStockHistory(symbol, 60),
    3000
  ).catch(() => null);

  // Merge history into raw record if available
  // History takes priority over static DB fields
  const enrichedRaw = history && history.sessionCount > 0
    ? {
        ...raw,
        netFlowHistory:  history.netFlowHistory.length > 0
                           ? history.netFlowHistory
                           : raw.netFlowHistory,
        priceHistory:    history.priceHistory.length > 0
                           ? history.priceHistory
                           : raw.priceHistory,
        avg20dValue:     history.avg20dValue ?? raw.avg20dValue,
        _m6ScoreHistory: history.m6ScoreHistory.length > 0
                           ? history.m6ScoreHistory
                           : raw._m6ScoreHistory,
      }
    : raw;

  // M6 history for M16: from historyBuilder (prior sessions only)
  // Falls back to getM6History if historyBuilder unavailable
  const m6History = (history?.m6ScoreHistory.length ?? 0) > 0
    ? history!.m6ScoreHistory
    : await withTimeout(
        getM6History(symbol, 5),
        2000
      ).catch(() => [] as number[]);

  const input = buildBandarmologyInput(enrichedRaw, m6History);
