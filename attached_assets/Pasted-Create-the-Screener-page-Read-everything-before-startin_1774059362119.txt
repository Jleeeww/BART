FILTER LOGIC (client-side, no new API calls):

Fetch stocks from GET /api/stocks on mount.
Apply all active filters simultaneously:

Rezim filter:
  If "Semua" selected → no filter
  Map selection to stock data:
    "Akumulasi" → stock regime contains "ACCUMULATION" 
                  OR flowBias === "Akumulasi"
    "Transisi"  → regime contains "TRANSITION" or "FADING"
    "Distribusi"→ regime contains "DISTRIBUTION" 
                  OR flowBias === "Distribusi"
    "Volatile"  → regime contains "VOLATILE"

Posisi Siklus filter:
  If "Semua" → no filter
  Derive cyclePosition client-side from stock data
  (same useMemo logic as StockDashboard)
  Match selected labels to cyclePosition values

Skor filter:
  stock.readiness >= selectedMinScore

Sektor filter:
  If "Semua" → no filter
  stock.sector === selectedSector

Aliran Dana filter:
  If "Semua" → no filter
  stock.flowBias === selected (Akumulasi/Netral/Distribusi)

Sort logic:
  "Skor ↓": sort by readiness descending
  "Skor ↑": sort by readiness ascending
  "Nama A–Z": sort by symbol ascending
  "Perubahan ↓": sort by changePercent descending
