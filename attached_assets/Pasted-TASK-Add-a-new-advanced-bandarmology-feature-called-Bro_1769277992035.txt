TASK: Add a new advanced bandarmology feature called Broker Stability Score that measures whether the same brokers consistently dominate accumulation across multiple periods. This helps detect true operator campaigns vs temporary positioning.

BACKEND CHANGES (server/routes.ts)

Create a new function:

Function name: calculateBrokerStabilityScore

Purpose:
Track broker dominance persistence across time and return a stability score from 0–100.

Logic:

• Input: Historical broker flow data (array of daily broker summaries)
Each day contains:

{
  date: string,
  brokers: [
    { code: string, netBuy: number, netSell: number }
  ]
}


• Step 1 — For each day:

Compute net flow per broker = netBuy − netSell

Identify Top 3 brokers with highest positive net flow

• Step 2 — Track frequency:

Count how many times each broker appears in Top 3 across all days

• Step 3 — Compute Stability Score:

stabilityScore = (total appearances of top recurring brokers) / (total top-3 slots across all days) * 100


• Step 4 — Classify:

Score	Stability Level	Meaning
<40	Low Stability	Flow leadership changes frequently
40–69	Moderate Stability	Some recurring accumulation
≥70	High Stability	Strong operator-style persistent accumulation

• Step 5 — Return:

{
  score: number,
  level: "Low" | "Moderate" | "High",
  interpretation: string
}


Interpretation Text Rules:

Low: "Accumulation leadership is rotating. This suggests short-term positioning rather than a coordinated institutional campaign."

Moderate: "Some brokers are repeatedly active, indicating emerging institutional interest but not full control."

High: "The same brokers consistently dominate accumulation, signaling a structured operator-style campaign with sustained intent."
