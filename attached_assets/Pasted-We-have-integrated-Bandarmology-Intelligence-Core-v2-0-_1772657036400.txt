STEP 3 — REPLACE OLD DECISION SYSTEM

The existing system uses the v1.1 decision logic:

BUY / WATCHLIST / AVOID

based on v1 scores.

Replace this with a new decision function using the v2 composite score.

Create new file:

server/engine/bandarmologyDecisionV2.ts

Add the function:

export function getBandarmologyDecisionV2(result) {

  const score = result.composite.score;
  const regime = result.M16_regimeStability.regime;

  if (score >= 70 && regime === "ACCUMULATION") {
    return "WATCHLIST_PRIORITAS";
  }

  if (score >= 55) {
    return "SIAP_DIPANTAU";
  }

  if (score < 40) {
    return "HINDARI_DULU";
  }

  return "NETRAL";
}
